# 样式处理（仅特殊情况调用）

## 定位

这个 skill **默认不需要使用**。只有在遇到“样式方案不稳定/易误伤/国际化文案长度变化导致布局崩坏”等**特殊情况**时才来查阅这里的参考处理。

- 当你需要处理 **国际化左右文本弹性布局**（左侧文案不定长，右侧按钮/金额等需要贴边且不被挤压）时，去阅读：`@.cursor/skills/style-handling/references/左右文本弹性布局.md`
