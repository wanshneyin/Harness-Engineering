## 场景：国际化 -—— 左右文本弹性布局 —— 右文本不可压缩，左文本宽度动态适应

### 问题背景

一行内左右两段文本，多语言下文本长度不可控。需求：
- **右文本**：有一个最大宽度上限，但不可被压缩（即使左文本再长，右文本也保持完整）
- **左文本**：填满剩余空间，最大宽度随右文本实际宽度动态变化，超出则截断/换行

### 核心思路

利用 flex 布局中 `flex-shrink: 0` 与 `flex: auto` 的配合：
- 右侧 `flex-shrink: 0` → 声明不可压缩，优先保证自身宽度
- 左侧 `flex: auto`（即 `flex: 1 1 auto`）→ 自动吃满剩余空间，宽度 = 父容器 - 右侧实际宽度

### 代码示例（BottomSell.vue）

**HTML 结构**
```html
<div class="test_main">
  <!-- 左文本：flex: auto 吃满剩余宽度 -->
  <div class="test_main_left">
    <div class="test_main_left_text">{{ statusText }}</div>
    <div>></div>
  </div>
  <!-- 右文本：flex-shrink: 0 不可压缩 -->
  <div class="test_main_right">
    <div class="test_main_right_text">{{ rightText }}</div>
    <div>:</div>
  </div>
</div>
```

**CSS 关键样式**
```scss
.test_main {
  display: flex;
  justify-content: space-between;
  width: 100%;

  // --------- 左侧 ---------
  .test_main_left {
    flex: auto;            // 关键：自动填满剩余空间
    display: flex;
    align-items: center;
    margin-right: 13px;    // 左右间距
  }
  .test_main_left_text {
    overflow: hidden;
    display: -webkit-box;
    -webkit-line-clamp: 2; // 最多2行（根据情况处理）
    line-clamp: 2;
    -webkit-box-orient: vertical;
    word-break: break-word;
    line-height: 20px;
  }

  // --------- 右侧 ---------
  .test_main_right {
    flex-shrink: 0;        // 关键：不可压缩
    display: flex;
    align-items: center;
    justify-content: flex-end;
    .test_main_right_text {
      max-width: 100px;   // 设置最大宽度
    }
  }
}
```

### 原理总结

```
┌─────────────────────────────────────────┐
│ 父容器  display: flex; width: 100%      │
│                                         │
│  ┌─ 左 (flex:auto) ──┐  ┌─ 右 (shrink:0) ─┐
│  │ 自动吃满剩余空间    │  │ 宽度由内容决定    │
│  │ 超出 line-clamp    │  │ 不可被压缩        │
│  │ 截断               │  │ 可设 max-width   │
│  └────────────────────┘  └─────────────────┘
│                                         │
│  左max宽度 = 父宽度 - 右实际宽度 - gap    │
└─────────────────────────────────────────┘
```

| 属性 | 左文本 | 右文本 |
|------|--------|--------|
| flex | `flex: auto` (可伸可缩) | 默认（不设 flex） |
| flex-shrink | 默认 1（可压缩，但被 flex:auto 接管） | `0`（不可压缩） |
| 宽度约束 | 自动 = 剩余空间 | `max-width` 控制上限 |
| 溢出处理 | `-webkit-line-clamp` 多行截断 | 同理可加截断 |

### 适用场景

- 多语言环境下，左右文本长度都不确定
- 需要保证某一侧文本完整显示，另一侧自适应
- 标签 + 值、状态文本 + 操作文本 等左右对称布局
